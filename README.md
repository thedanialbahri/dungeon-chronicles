# Dungeon Chronicles

**Dungeon Chronicles** is a text-based role-playing game (RPG) developed in Python. Players embark on a fantasy adventure through a dangerous dungeon, battling enemies, managing limited resources, collecting equipment, and making strategic decisions to survive.

The objective is to recover the legendary **Heart of Ember**, a powerful artefact hidden deep within the dungeon and guarded by a formidable enemy.

The game is designed around turn-based combat, exploration, and resource management. Every decision matters, as defeat means starting the adventure again.

## Project Overview

Dungeon Chronicles is a personal software engineering portfolio project focused on developing practical Python programming skills through building a complete, playable application.

The project aims to demonstrate fundamental software engineering principles, including application design, state management, input validation, data persistence, automated testing, and maintainable code.

### Planned Features

- **Text-Based Exploration:** Navigate five interconnected dungeon locations using text commands.
- **Turn-Based Combat:** Battle enemies using attack, defence, and healing actions.
- **Character Management:** Track player health, attack, defence, and equipment.
- **Inventory System:** Collect, manage, and use items with limited inventory capacity.
- **Resource Management:** Make strategic decisions about healing, supplies, and survival.
- **Enemy Encounters:** Face multiple enemy types with different combat attributes.
- **Quest Progression:** Explore the dungeon, overcome challenges, and recover the Heart of Ember.
- **Permanent Defeat:** Losing all health ends the current adventure.
- **Save and Load:** Save progress and resume an unfinished adventure.
- **Input Validation:** Handle invalid commands and actions gracefully.

The primary goals of this project are to:

4. Practise automated testing, debugging, and error handling.
